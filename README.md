# Astro на Deno

Пример приложения [Astro](https://astro.build/) на [Deno](https://deno.com/) с серверным рендерингом (SSR).

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | `deno task build` |
| Команда запуска | `deno task start` |
| Порт приложения | `4321` |
| Путь проверки состояния | `/` |

Railpack видит `deno.json` и собирает проект в Deno. Команды сборки и запуска обязательны: для
Deno Railpack сам сборку не запускает, а для запуска выбрал бы не тот файл. Обе задачи описаны в
`deno.json`. Сервер собирается адаптером
[`@astrojs/node`](https://docs.astro.build/en/guides/integrations-guide/node/) в режиме
`standalone` и слушает `0.0.0.0` (`server.host: true` в `astro.config.mjs`). Порт берётся из
переменной окружения `PORT` — её передаёт платформа, — а без неё `4321`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
deno install --allow-scripts

# сборка для продакшн
deno task build

# запуск собранного серверного приложения
deno task start
```
